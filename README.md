# Evolu Scan

> This project is based on [React Scan](https://github.com/aidenybai/react-scan) by [Aiden Bai](https://github.com/sponsors/aidenybai)

## Installation

```bash
npm i @evolu/scan
```

## Usage

```tsx
import {createEvolu} from '@evolu/common'
import {scan} from '@evolu/scan'

const evolu = createEvolu(...)

scan({
  evolu,
  enabled: __DEV__,
})
```
